# 📊 Self Skill Awareness Dashboard

## 🔎 Project Overview
This project presents a data-driven analysis of self skill awareness distribution among participants using Microsoft Excel.  

The dashboard identifies performance gaps and highlights areas that require improvement through visual insights and KPI tracking.

---

## 📈 Dashboard Highlights
- **Total Responses:** 150  
- **Needs Improvement:** 75%  
- **On Track:** 20%  
- **Above Expectations:** 5%  

---

## 🛠 Tools & Techniques Used
- Microsoft Excel  
- Pivot Tables  
- Data Visualization  
- KPI Cards  
- Percentage Analysis  

---

## 🎯 Key Insights
- Majority of participants fall under **Needs Improvement**, indicating a significant skill gap.  
- Only a small percentage are high performers.  
- Structured training programs are necessary to improve overall performance levels.  

---

## 💡 Recommendations
- Conduct structured skill development training  
- Introduce mentoring and coaching programs  
- Monitor performance quarterly  
- Focus on shifting participants from **Needs Improvement** to **On Track**
